# SketchKnot

Manages digital artboards with customizable layouts and automatic grid systems for graphic designers.

With SketchKnot, you get a lightweight tool that stays out of your way.

**What you get**

- Manages digital artboards with customizable
- layouts and automatic grid systems
- for graphic designers

## Key Features

- Manages digital artboards with customizable
- layouts and automatic grid systems
- for graphic designers

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/programmerbnd/SketchKnot.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
